Project · 01
Change Risk Scoring Engine
Python 3.12 LangChain FAISS Ollama 131 tests
Problem

Every production change at a bank goes through a CAB. Analysts manually review each request, cross-reference past incidents, and write risk assessments. 30 to 60 minutes per change, with significant variance between reviewers. Conservative reviewers block changes, liberal ones miss critical risks.

Solution

An auditable change risk scoring tool that scores each change on 8 weighted risk dimensions, retrieves similar past changes via vector search, and generates a CAB-ready risk narrative on an on-premise LLM. Deterministic scoring stays auditable, the AI layer produces the explanation. Models inherent vs. residual risk so addressed mitigations are tracked across revisions and the Go/No-Go evolves with the program.

Impact

Replaces 30 to 60 minutes of manual review with a CAB-ready report in under a minute. The inherent vs. residual model gives reviewers a clear before/after as mitigations land. All processing local, designed for PCI DSS, SOX, and FFIEC environments.

Project · 02
Incident Pattern Analyzer
Python 3.12 LangChain FAISS 21 tests
Problem

Incident postmortems generate rich data, but most teams treat each incident as a one-off. Recurring root causes (the same timeout misconfigured across services, the same on-call gap, the same config drift) get re-discovered every quarter instead of surfaced as patterns.

Solution

An operational resilience tool that ingests incident records, embeds them via vector search, clusters by similarity, and produces a runbook-aware narrative explaining recurring patterns and which existing runbooks address each cluster. Built for SRE and ops leaders who need to turn 60+ incidents per quarter into actionable themes.

Impact

Surfaces recurring pain points that are invisible to one-incident-at-a-time review. Runbook awareness means recommendations point to existing tooling, not just "you should write a runbook." On-premise LLM, no data leaves the machine.

Project · 03
Program Status Report Generator
Python 3.12 LangChain Ollama 21 tests
Problem

Senior leaders ask for weekly program status reports synthesizing Jira items, project charters, and recent activity into a one-page summary. PMs spend 2 to 4 hours per week on this, and the output is uneven across PMs.

Solution

A stakeholder-aware reporting tool that ingests a Jira export and a project charter, generates a structured weekly report with status, risks, top tasks, and a narrative summary on an on-premise LLM. Templated where it can be, AI-narrated where prose is needed. Audit trail preserved end-to-end.

Impact

2 to 4 hours of weekly status writing collapsed into a generated draft that the PM edits in 15 minutes. Local LLM means it works in environments where cloud AI is forbidden.

Building Next

Five tools across the program lifecycle.

The next five AI tools I'm thinking about. Each lives in a different phase of the program lifecycle.

01
◆ Pre-kickoff

Pre-mortem question generator

Input a project plan. Output the top ten questions a smart pessimist would ask before kickoff, so risks get surfaced while there's still time to mitigate them.

02
◆ Planning

Roadmap reality check

Compares stated commitments against velocity and dependency data. Generates a confidence score for each milestone before the exec has to ask.

03
◆ Shipping

Launch readiness checklist generator

Input a feature description and target launch date. Output a tailored checklist covering legal, support, marketing, oncall, monitoring, and rollback. Owners and due dates filled in.

04
◆ Mid-execution

Sprint goal drift detector

Every Friday reads the sprint board, compares to the sprint goal, flags tickets that don't ladder up. Catches scope creep mid-sprint instead of mid-quarter.

05
◆ Post-incident

Postmortem quality scorer

Reads an incident postmortem and scores it on completeness covering root cause, contributing factors, action items, and blameless tone. Suggests what's missing.

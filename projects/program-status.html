Program Status Report Generator

Turns a Jira export and a project charter into a structured weekly status report on an on-premise LLM. Templated where it can be, AI-narrated where prose is needed. Audit trail preserved end-to-end.

Python 3.12 LangChain Ollama 21 tests Audit trail
·· The Problem

2 to 4 hours per week, per PM. The output is uneven.

Senior leaders ask for weekly program status reports synthesizing Jira items, project charters, and recent activity into a one-page summary. PMs spend 2 to 4 hours per week on this and the output is uneven across PMs.

  • ● Copy-pasting from filtered Jira views
  • ● Re-formatting the same template every week
  • ● Voice and detail level vary by PM
  • ● Cloud AI not allowed for sensitive program data
·· The Solution

Templated where it can be. AI-narrated where it should be.

A Python tool that ingests a Jira export and a project charter, generates a structured weekly report with status, risks, top tasks, and a narrative summary on an on-premise LLM. Audit trail preserved end-to-end.

  • ● Status, risks, top tasks templated from Jira
  • ● Charter context retrieved via RAG
  • ● Narrative summary on local LLM
  • ● All processing local, audit trail preserved
·· The Impact

From a half-day chore to a 15-minute edit.

·· What's in the report

A six-section weekly report, every section earned its place.

The output template is opinionated. Six sections, in this order, because that's the order an executive sponsor reads in. Each section comes from a specific source so the audit trail is reproducible. The narrative summary is the only AI-written part.

S1Overall status (RAG: G/A/R)
S2Top risks & mitigations
S3Top 5 tasks this week
S4Top 5 tasks next week
S5Decisions needed from sponsor
S6Narrative summary (AI-written)
·· Designed for

Senior PMs and program managers who write the same weekly status report 50 times a year. Risk and compliance teams who need a reproducible, audit-friendly output instead of free-text Slack updates. Anyone whose program data can't go to a cloud model.
